# 💰 Fin-Cntrl

Aplicação de gerenciamento de finanças pessoais — controle de rendas, gastos e cofrinhos com dashboard de estatísticas.

## 🔗 Demo

[Ver projeto ao vivo](https://luiz-reis-neves.github.io/fin-cntrl/)

## ✨ Funcionalidades

- Cadastro de rendas e gastos
- Criação e gerenciamento de cofrinhos
- Dashboard com estatísticas e gráficos
- Interface responsiva

## 🛠️ Tecnologias

- HTML
- CSS
- Tailwind CSS
- JavaScript Vanilla
- Vite

## 🚀 Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/Luiz-Reis-Neves/fin-cntrl.git

# Entre na pasta
cd fin-cntrl

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

## 📌 Sobre

Projeto desenvolvido para aprofundar conhecimentos em JavaScript Vanilla antes de migrar para um framework.
